- **Statut** : acceptée | à confirmer | remplacée par ADR-NNN

Contexte : le problème, les contraintes, ce qui rend une décision nécessaire.

Alternatives : les options envisagées et pourquoi elles sont écartées.

Décision : ce qui est retenu, formulé pour être appliqué sans ambiguïté.

Conséquences : ce que cela change (code, processus, dette), y compris les inconvénients assumés.
